# MoneyMate
MoneyMate is a personal finance management system that helps users track their income and expenses in an organized way. The platform allows users to categorize transactions, view spending patterns through charts and dashboards, and monitor their financial activity over time.

# Features
The frontend of MoneyMate is developed using Flutter to provide a smooth and responsive cross-platform experience on web and mobile.

The backend is built using Node.js and Express.js to handle application logic and server-side processing efficiently.

The application uses PostgreSQL for secure, structured, and scalable data storage.

Email notifications for alerts such as overspending and upcoming bills are implemented using Gmail integration.

The system ensures smooth communication between frontend and backend for handling user data and financial operations.

The application is designed with scalability in mind to support future enhancements and feature expansion.
